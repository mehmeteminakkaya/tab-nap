# Tab Nap Privacy Policy

Tab Nap does not collect, transmit, sell or share any personal data.

The only data it handles is the list of tabs you snooze (each tab's address, title, icon address and wake-up time). This list is stored locally in your browser with Chrome's `storage` API and never leaves your device. Uninstalling the extension deletes it.

Tab Nap has no server, no analytics and no third-party code.

Questions: open an issue on the project's GitHub page.
